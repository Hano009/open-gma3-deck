grandMA3 setup (Menu → In & Out → OSC): add a line with Destination IP = this computer, Port = the port above, Prefix = the prefix above, and enable Receive and Receive Command. Enable Send with destination port = the feedback port for live executor feedback. Then enable Enable Input and Enable Output for OSC in the same menu.

Names and feedback: add a second OSC line with Destination IP = this computer, Port = the feedback port, Receive = No, Send = Yes and Send Command = Yes. Enter that line's number as Feedback line.
